# 吉利银河A7 3个月驾驶体验


## 简述 

笔者自从购买吉利银河A7 到现在已经3个月了， 写写用车感受，  简单总结一下就是：
- 车的外观笔者喜欢，内饰感觉不出个所以然，但是也顺眼。
- 动力感觉市区提速还可以， 但也没那么夸张， 笔者一直用智能模式， 没有用性能模式。
- 前方通过预警，后方通过预警， 旁边有车的提示都不错。  HUD 看看车速也很好用。
- 漆太薄
- 4s店太拉胯

## 详细描述

### 买车

买车的时候4s店的销售和笔者说保险6500， 结果付钱的时候 6800+  。  这就造成销售给笔者算的落地价不是落地价格，是估计落地价。  有点离谱了。 

给了上牌服务费300，自己交的工本费120， 然后上牌几乎都是4s帮忙跑的。 

### 车的配置

这个其实直接看懂车帝 / 汽车之家就有了， 不过笔者还是简单的描述一下把。 
笔者买的是 150KM 探索➕版本。 
- 插混汽车， 电力 WLTC续航120  CLTC续航150  油箱60L
- 360,  哨兵模式
- 行车记录仪 （只能记录前向的， 不是四向的）
- 前方碰撞预警（很迟钝）  前方，后方通过预警
- HUD   显示简短的导航信息，地图信息（红绿灯，摄像头等），车速，挡位
- 18.4度电池
- ICC， 高速NOA 。   笔者只尝试了 高速ICC，在堵车和隧道，以及白天没车的时候用了。 听说NOA变道频繁 所以就没用。 
- 没有收音机， 但是可以用 网络听，  有一个自带的云听APP 可以搜索电台

### 漆薄

笔者从地库上来的时候蹭了一个直角墙角， 然后车门有点变形， 叶子板也变形了。  车门变形后，内部的漆直接被顶破了，可以用手直接扣掉了

笔者有次上班的时候看到比亚迪被追尾 车门有个坑 都没掉漆。。

### 拉胯的4s店

笔者是在杭州买的车， 然后。。。 
- 笔者买车的4s店 只卖车， 别的都不管
- 去了一个其他的4s店， 只能做保养和卖车， 不能做油漆
- 最后到了一个能做油漆的4s店， 给笔者做完油漆， 车门部分还留了一个漆的缝隙， 然后座椅被弄的很脏。。
  - 联系了一下说 给笔者两张保养的工时券，算有点诚意，但不大。   另外笔者现在还没收到。。
